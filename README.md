# Моя доска — переносимый архив

Готовая статическая версия планировщика для GitHub Pages и ASUSTOR NAS.

## Важно о хранении данных

Эта переносимая версия сохраняет проекты и задачи локально в браузере (`localStorage`). Данные остаются в том браузере и на том устройстве, где вы их ввели; они не синхронизируются между GitHub, NAS, телефонами и компьютерами. Периодически скачивайте JSON или CSV из меню «Данные проекта» для резервной копии и переноса.

## Запуск на ASUSTOR AS5004T

Самый простой способ — встроенный Web Center, без Docker:

1. В ADM откройте **Web Center** и включите **Web server**. Если ADM попросит установить веб-сервер, установите предложенный пакет.
2. В файловом менеджере ADM откройте общую папку **Web** и создайте в ней папку `planner`.
3. Скопируйте в `Web/planner` всё содержимое папки `site` из архива — `index.html` и каталог `assets`.
4. Откройте в локальной сети `http://АДРЕС-NAS/planner/`.

Если Web Center отсутствует в вашей версии ADM, можно использовать Docker Engine, если он доступен в App Central для установленной версии ADM:

1. Скопируйте весь архив в общую папку NAS, например `/volume1/Share/planner`.
2. Через SSH перейдите в эту папку и запустите `docker compose up -d --build`.
3. Откройте `http://АДРЕС-NAS:8088/`.

Вместо SSH можно создать стек с этим `docker-compose.yml` через Portainer, если он установлен. Порт веб-интерфейса — `8088`; его можно изменить в `docker-compose.yml`.

## Публикация на GitHub Pages

1. Распакуйте архив и загрузите его содержимое в новый GitHub-репозиторий. Папки `.github` и `site` должны оказаться в корне репозитория.
2. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации.
3. Отправьте изменения в ветку `main` (или вручную запустите workflow **Deploy GitHub Pages** во вкладке **Actions**).
4. Адрес опубликованной страницы GitHub покажет в **Settings → Pages**.

GitHub Pages сделает страницу общедоступной. Сам сайт не отправляет содержимое планировщика на GitHub, но все записи остаются только в локальном браузере. Не вводите конфиденциальные данные на общедоступном устройстве.

## Что находится в архиве

- `site/` — готовый сайт, можно сразу загрузить в GitHub Pages или в папку Web на NAS.
- `.github/workflows/deploy-pages.yml` — автоматическая публикация на GitHub Pages.
- `Dockerfile`, `docker-compose.yml`, `nginx.conf` — альтернативный запуск через контейнер.
